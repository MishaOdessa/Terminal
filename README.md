# Terminal Emulator (Godot 4)

Эмулятор терминала Linux, разработанный на движке **Godot 4** (GDScript) с поддержкой виртуальной файловой системы (VFS) на базе ZIP-архивов и автоматическим исполнением стартовых скриптов.

## Особенности
* **Интерфейс командной строки:** Динамический промпт (`user@os:dir$`), история команд и поле ввода.
* **Виртуальная файловая система (VFS):** Монтирование ZIP-архива напрямую в оперативную память без распаковки на диск с помощью `ZIPReader`.
* **Парсер CLI-аргументов:** Поддержка флагов `--vfs` и `--script` при запуске.
* **Подстановка переменных:** Автоматическое расширение переменных окружения (например, `$USER`).
* **Автоматизация тестов:** Выполнение последовательности команд из внешнего сценария при старте.
* **Встроенные команды:** `ls`, `cd`, `echo`, `clear`, `exit`.
