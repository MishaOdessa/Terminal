# Terminal Emulator (Godot 4)

Эмулятор терминала Linux, разработанный на движке **Godot 4** (GDScript) с поддержкой виртуальной файловой системы (VFS) на базе ZIP-архивов и автоматическим исполнением стартовых скриптов.

Все операции с VFS выполняются в памяти: архив на диске не распаковывается и не изменяется. Команды `chown` и `rmdir` меняют только состояние в памяти, после закрытия эмулятора всё возвращается к исходному виду.

## Запуск

Перейдите в директорию, где находится проект, и выполните:

```
./run.sh
```

Запуск с параметрами (передаются после `--`):

```
godot --path . -- --vfs <путь> --script <путь>
```

| Параметр | Описание |
|---|---|
| `--vfs <путь>` | путь к ZIP-архиву с виртуальной файловой системой |
| `--script <путь>` | путь к стартовому скрипту |

При запуске эмулятор выводит заданные параметры (отладочный вывод).

## Возможности

В командах раскрываются переменные окружения реальной ОС (например, `$HOME`, `$USER`).

| Команда | Описание |
|---|---|
| `ls [-a] [-l] [-h]` | Показывает содержимое текущей папки. `-a` показывает скрытые файлы, `-l` подробный формат (права, владелец, группа, размер, дата изменения), `-h` размеры в читаемом виде (K, M) |
| `cd [папка]` | Переходит в папку на один уровень вглубь. `cd ..` поднимается на уровень вверх, `cd` без аргумента возвращает в корень `~` |
| `date` | Выводит текущую дату и время |
| `uptime` | Выводит время работы эмулятора |
| `uname [-a]` | Выводит название ОС. С флагом `-a` (или `--all`) ещё и имя хоста, версию и процессор |
| `chown [user][:group] файл...` | Меняет владельца и/или группу файлов и папок. Формы: `user`, `user:group`, `:group`. Допустимые имена: `root` и текущий пользователь. Время изменения обновляется |
| `rmdir папка...` | Удаляет пустые папки (только в памяти) |
| `clear` | Очищает экран |
| `help` | Выводит список команд с описанием |
| `exit` | Закрывает эмулятор |
