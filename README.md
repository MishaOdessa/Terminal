# Linux Terminal Emulator in Godot (Этап 3: Виртуальная файловая система VFS)

Эмулятор терминала Linux на движке Godot Engine (GDScript). На третьем этапе реализована работа с виртуальной файловой системой (VFS) в оперативной памяти на базе ZIP-архивов без распаковки на физический диск.

## Реализованные требования (Этап 3)

1. **Работа VFS в памяти:**
   - Все операции чтения, поиска и навигации по каталогам выполняются исключительно в оперативке. Запрещена распаковка или изменение данных на диске.
2. **Источники VFS (ZIP-архивы):**
   - Поддерживается подключение различных вариантов виртуальной файловой системы через архивы: `vfs_minimal.zip`, `vfs_t_multi.zip` и `vfs_deep.zip` (с глубиной вложенности от 3 уровней).
3. **Скрипты ОС для тестирования:**
   - Созданы и настроены скрипты автоматического запуска различных конфигураций VFS (`run_minimal.sh`, `run_multi.sh`, `run_deep.sh`).
4. **Конфигурационные и тестовые сценарии:**
   - Подготовлены файлы сценариев для проверки корректной работы (`good_test.ini`) и обработки ошибок (`bad_test.ini`).
5. **Контроль версий:**
   - Результаты этапа зафиксированы в репозитории стандартно оформленным коммитом.

## Инструкция по запуску тестов VFS

./tests/run_multi.sh
